# Qualitätscheck Schulsozialarbeit Niedersachsen

Interaktive Checkliste zu den Rahmenbedingungen der sozialen Arbeit in schulischer Verantwortung in Niedersachsen: 60 Kriterien in 9 Bereichen (Basis, Erweitert, Exzellenz), automatische Auswertung mit Ampel, Maßnahmenplan und Druckfassung.

Alle Eingaben bleiben lokal im Browser. Es werden keine Daten übertragen.

Private Arbeitshilfe, kein amtliches Dokument des Landes Niedersachsen oder des RLSB. Stand: November 2026.
